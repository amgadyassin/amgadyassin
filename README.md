### 📌 Featured Flagship Projects

#### 🏗️ [Enterprise Cloud Modernization: Oracle to Microsoft Fabric](https://amgadyassin.github.io/#projects)
> **Modernized legacy on-prem Oracle databases into a unified Microsoft Fabric OneLake Lakehouse using Medallion Architecture.**

* **Pipeline Flow**: `Oracle / SFDA Source` ➔ `Azure Blob & Dataflows Gen2` ➔ `OneLake Bronze/Silver Delta` ➔ `Gold Star Schema` ➔ `Power BI Direct Lake`
* **Scale & Complexity**: Migrated 300+ tables with tens of millions of records under strict SFDA healthcare regulatory governance.
* **Key Results**: Replaced 5,000+ lines of complex procedural PL/SQL, achieving an **80% reduction in ETL batch time** and sustaining **99.9% data availability** across enterprise reporting.
* **Stack**: `Microsoft Fabric` · `OneLake` · `PySpark` · `Dataflows Gen2` · `Power BI (Direct Lake)` · `DAX` · `T-SQL`
